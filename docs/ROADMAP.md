# JevBench v0.1 — 3-Day Plan

## Day 1
Recover and verify the **largest available official scenario set**, including scenarios with no existing questions, and avoid aggressive filtering at this stage. Build a complete coverage table with the number of Noul, Choice, and Score questions for every scenario.

## Day 2
Perform light scenario-level filtering only for clear duplicates, incomplete cases, or near-equivalent examples, while preserving dataset scale. Expand under-covered scenarios toward a common target of ~10 questions per scenario and an overall Noul:Choice:Score ratio close to 4:4:2.

## Day 3
Annotate human-verified gold answers for all retained questions, including explicit rubrics for Score questions and adjudication for disagreements. Produce JevBench-Clean v0.1, report dataset statistics and clean performance, and prepare the paired adversarial benchmark format.
